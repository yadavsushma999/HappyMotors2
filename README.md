# 🚗 Auto Garage - Static Website

A responsive auto garage website built using **react (React + TailwindCSS components)** and powered by **Vite** for fast performance. Perfect for showcasing services like repairs, maintenance, bookings, and more.

---

## 🔥 Features

- ⚡ Built with Vite for blazing-fast development
- 🎨 react components with TailwindCSS for modern UI
- 🌗 Light/Dark mode toggle
- 📱 Fully responsive design (mobile-first)
- 🛠 Static content with smooth scrolling sections
- 📅 Booking/appointment-ready layout (Google Calendar embedded)
